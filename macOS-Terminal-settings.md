# Notes on my Terminal.app settings

I've used third-party macOS terminals — **iTerm**, **Ghostty** — in the
past. I now rely on the default Terminal in Applications > Utilities.

## Profile: Basic 80 × 25

- **Terminal** > Settings:
  - Profiles:
    - Profile: “**Basic**” _Default_
      - This profile is responsive to system dark mode setting
    - Text:
      - Font: **Cascadia Mono NF** Regular 16
      - Antialias text
      - Use bold fonts
      - Allow blinking text
      - Display ANSI colors
      - Dynamic foreground colors
      - Cursor: Block
      - Blink cursor
    - Window:
      - Window Size: 80 × 25
- Edit:
  - **<kbd>Option</kbd>-<kbd>Command</kbd>-<kbd>M</kbd>**:
    Toggle Option / Meta

When using a MacBook Air 15-inch at Default (1710 × 1107),
a Terminal window taking up 50% width and 100% height
is 93 columns by 53 rows (52 rows if window has tabs).
